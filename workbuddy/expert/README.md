# ValueScope · DCF 估值分析师

一个绑定 [ValueScope](https://valuescope.app) 确定性 DCF 引擎的 WorkBuddy 专家。

**分工**：你负责前瞻判断，引擎负责数据和计算。专家会先取历史财务区间，联网研究业绩指引与
分析师一致预期，逐项推理每个假设，再调用引擎算出内在价值、敏感性矩阵和反向 DCF——
同样的输入永远得到同样的结果，估值的变化只来自基本面。

**支持市场**：A股 `600519.SS` / `000333.SZ`、港股 `0700.HK`、美股 `AAPL`、日股 `7203.T`。
A股与港股无需任何密钥；美股 / 日股有每日限量的免费体验额度，超出后需自带
[FMP](https://financialmodelingprep.com) key。

**MCP 服务**：`https://mcp.valuescope.app/mcp`（streamable HTTP）
**源码**：https://github.com/alanhewenyu/ValueScope （AGPL-3.0）

估值输出仅供研究参考，不构成投资建议。
